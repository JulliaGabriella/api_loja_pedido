## ▶️ Como Executar o Projeto

### 1️⃣ Clonar o repositório

```bash
git clone https://github.com/JulliaGabriella/api_loja_pedido.git
```

---

### 2️⃣ Backend

Entrar na pasta da API:

```bash
cd ApiDBLojaJV
```

Executar:

```bash
dotnet run
```

---

### 3️⃣ Frontend

Abrir o arquivo:

```bash
index.html
```

ou utilizar a extensão Live Server no VS Code.
